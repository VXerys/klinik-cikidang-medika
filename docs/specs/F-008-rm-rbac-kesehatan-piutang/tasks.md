## Residual Risk / Follow-up

- Nominal tarif komisi rujukan belum ditetapkan klinik. Input nominal masih manual dan harus dikonfirmasi owner.
- Pemetaan desa legacy (`Tamansari`, `Gunungmalang`, `Bumiasih`, `Nangerang`) dipertahankan sebagai alias agar data lama tidak rusak, menunggu konfirmasi standar desa resmi.
- Halaman baru belum memiliki pengujian otomatis karena test runner belum dikonfigurasi di repositori.
- Quick therapy packages and the drug catalog live in source configuration (`src/constants/prescriptions.ts`, `src/components/rekam-medis/PrescriptionQuickPicker.tsx`), so changes require a developer and a redeploy. A clinic-managed master data screen is a Post-MVP proposal, not part of this slice.
- Procedure and point-of-care lab entry remain free-text; a selectable procedure list is a Post-MVP proposal.
- The dropdown popover is clipped inside scrolling modal containers; a portal-based popover is the follow-up fix if it proves disruptive.
- Deliverable: `docs/product/Laporan_Pembaruan_Sistem_F008.pdf`, generated by `scripts/generate_f008_update_report_pdf.py`.
