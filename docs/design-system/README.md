# Sistem Desain & Panduan Revamp UI/UX
*SIM Klinik Pratama Cikidang Medika*

Folder ini berisi spesifikasi sistem desain lengkap, aturan komponen, standar copywriting, dan file pratinjau HTML interaktif untuk memodernisasi tampilan antarmuka web klinik.

---

## 📁 Struktur Berkas

| Berkas | Deskripsi Isi |
|---|---|
| 📄 [`component-showcase.html`](./component-showcase.html) | **Pratinjau Interaktif Komponen**. Buka file ini langsung di browser Anda untuk menguji tombol, warna, kartu, avatar, form pencarian, dan dialog modal secara interaktif. |
| 📘 [`01-DESIGN-FOUNDATION.md`](./01-DESIGN-FOUNDATION.md) | Filosofi *Clinical Modernism* (sintesis Chronyx & Elera), palet warna semantik, tipografi Plus Jakarta Sans, elevasi, dan radius konsentris. |
| 📗 [`02-COMPONENT-SPECIFICATIONS.md`](./02-COMPONENT-SPECIFICATIONS.md) | Spesifikasi detail setiap komponen: Tombol taktil, kartu KPI, bilah pencarian universal Ctrl+K, avatar inisial, tabel data, dan widget tanda vital dokter. |
| 📙 [`03-RBAC-ROLE-ADAPTATIONS.md`](./03-RBAC-ROLE-ADAPTATIONS.md) | Penyesuaian antarmuka untuk 3 peran klinik: Kasir/Pendaftaran, Dokter/Tenaga Medis, dan Pimpinan/Owner. |
| 📕 [`04-COPYWRITING-STANDARDS.md`](./04-COPYWRITING-STANDARDS.md) | Standar copywriting ramah dan anti-slop, kamus istilah klinik bahasa Indonesia, dan aturan label tombol aksi. |
| 📓 [`05-IMPLEMENTATION-ROADMAP.md`](./05-IMPLEMENTATION-ROADMAP.md) | Rencana bertahap penerapan gaya ke kode Next.js tanpa menyentuh fungsionalitas dan logika database. |

## 🚀 Cara Melihat & Mereview Pratinjau Komponen

1. Buka File Explorer di komputer Anda.
2. Masuk ke direktori: `d:\Projects\klinik-cikidang-medika\docs\design-system\`
3. **Klik ganda** pada berkas:
   ```
   component-showcase.html
   ```
4. File akan terbuka langsung di browser (Chrome, Edge, Firefox) dan Anda dapat mencoba semua tombol, animasi klik, pratinjau modal, dan dropdown pencarian!
