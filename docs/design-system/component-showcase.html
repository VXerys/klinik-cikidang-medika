Mengapa Dropdown Kustom Ini Lebih Unggul?

  • ✓ Bebas Pop-up Kotak Kaku OS: Dropdown native Windows membuka persegi panjang biru tanpa border-radius. Komponen ini memiliki sudut melengkung 16px proporsional (*concentric radius*).
  • ✓ Informasi Bertingkat (Sub-label): Tidak hanya nama "BPJS", tetapi juga menerangkan status "Tercover Kapitasi" sehingga petugas baru tidak salah pilih.
  • ✓ Aksesibilitas & Taktil: Mendukung klik di luar untuk menutup (*click outside*) dan rotasi chevron 180 derajat yang mulus.
